# 鸿蒙测试分发

向其他用户分发时，使用注册应用对应的发布签名。调试签名仅适用于 Profile 中配置的测试设备。以下命令与路径均相对项目根目录。

## 发布包

1. 在 AppGallery Connect 创建或选择 HarmonyOS 应用，包名与工程中的 `com.corelab.core2048` 保持一致。
2. 为该应用准备匹配的发布密钥库、证书和 Profile。
3. 在 DevEco Studio 的 **Signing Configs** 中配置 `release` 签名，并将 `release` 产品关联到该签名。
4. 在项目根目录执行：

```powershell
npm run harmony:release
```

APP/HAP 输出到 `artifacts/release/`。构建成功后检查签名与包名，向平台上传签名 APP。换电脑构建需重新配置签名材料及其本机路径；源码归档会移除个人签名配置。

## 提交测试

在应用控制台选择可用的测试分发入口，创建测试群组和测试版本，上传签名包，填写版本说明并按平台要求提交。入口、资格与审核要求以控制台为准。平台处理完成后，获取安装入口并提供给受邀测试用户。

出现软件包检测失败时，先查看平台的具体错误详情，再核对签名、Profile、包名和版本配置。

## 应用介绍

核芯2048是一款离线益智小游戏。滑动相同数字进行合并，挑战2048与更高数字。支持合并音效、动画、触感反馈、自动存档与历史最高分，可调整声音和动效设置。

## 隐私信息

游戏不要求注册或登录，不申请网络权限，未接入广告、统计、支付或云存档 SDK。棋盘、分数、记录与偏好保存在本机，触感使用震动权限。平台隐私表单和正式隐私声明还需填写发布主体及联系方式。
