# 测试与验证

以下命令与路径均相对项目根目录。

## 自动化检查

```powershell
npm test
npm run build
```

测试覆盖规则、四方向移动与随机棋盘、存档校验与存储故障恢复、音效输出与频率参数、离线网页脚本可执行性。构建生成 `dist/`，并更新鸿蒙内置网页资源。

## 隔离场景

运行 `npm run qa` 后访问：

| 地址 | 场景 |
| --- | --- |
| `http://127.0.0.1:2050/win?reset=1` | 两枚 1024 合成 2048，确认可继续游戏 |
| `http://127.0.0.1:2050/lose?reset=1` | 死局与重新开始 |
| `http://127.0.0.1:2050/lifecycle?reset=1` | 模拟后台、前台、返回与原生存档 |
| `http://127.0.0.1:2050/colors?reset=1` | 各级数字颜色 |

这些场景使用端口 `2050` 与模拟原生接口，不会覆盖端口 `2048` 的游戏存档。模拟接口不能代替真机生命周期与震动测试。

## 手动验收

- 触屏滑动和键盘移动正常，手势拖出棋盘后仍可完成移动；棋盘外拖动不触发移动。
- 小屏与横屏下棋盘、分数、重新开始和底部入口可用，页面不意外滚动。
- 重新开始归零当前分数并保留最高分；合成 2048 后可继续；死局可开始新局。
- 声音、音量、震动、动效设置正常，关闭再打开后设置与棋盘恢复。
- 旧存档可恢复当前棋盘，忽略已移除的撤销记录。
- 真机切入后台后计时和音频暂停，返回前台后可继续。
- 系统返回先关闭弹窗，在主界面可退出。
- 音效测试页可试听、分声部试听、调节频率和保存参数，游戏存档不受影响。
