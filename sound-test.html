参数实验 / MERGE

听见数字的变化。

合并数字越大，音调越高。连续有合并的有效移动会累计连击；有效移动没有合并时，连击归零。受阻移动不重置连击。

音高最多计算 6 连击，7 次以上与 6 次相同。0 可模拟还未连击时的设置试听；游戏中的实际合并从 1 开始。

64+64→128

128：加入延迟泛音，听感更丰富。

设置里的体验按钮在同一次操作中叠加点击音和 128 合并音；沿用当前连击次数。

声部分解 / INSIDE A MERGE

你听到的“咚”与“叮”。

听感上可以分成碰撞和音调两组。代码实际上叠加了多个声部，单独试听就能找到你听到的那个声音。

A / 碰撞组

低频冲击 + 高频噪声。
一起构成开头短促的“咚／咔”。

B / 音调组

上滑主音 + 高音尾音 + 延迟泛音。
构成电子感的“啾／叮”和余韵，64 以下没有延迟泛音。

各声部的时间安排0 → 400 ms

独奏保留游戏中的原始音量比例，没有额外放大。延迟泛音是另一个振荡器声部，并非录音回声。若试听的是设置里的体验按钮，还会额外叠加独立点击音。

触发规则 / NOTES

这些细节也会影响声音。

  • 一次操作只选一种移动反馈没有位移 → 受阻音；有位移、无合并 → 移动音；发生合并 → 合并音。同一步多组合并只响一次，取本步最大的合并结果。
  • 2048 会响两次先播放 2048 合并音，之后弹出胜利窗口时播放胜利旋律。有动效时约隔 515 毫秒，关闭动效时约隔 400 毫秒。选择继续后，后续合并不再弹出胜利窗口。
  • 按钮与设置导航、重新开始及确认、关闭、继续等操作按钮会播放点击音。音效／触感／动效开关变化也会尝试播放点击音；音量滑块本身没有试听音。关闭音效的那次切换不会响，重新打开会响。
  • 没有独立音效的时刻新数字生成、加分、记录更新、游戏结束、仅触摸棋盘而未滑动、Esc 或点弹窗外关闭窗口，都没有单独音效。
  • 什么时候静音游戏音效开关关闭、音量为 0 或音频未启用时不会响。切到后台会暂停音频；回到前台后通过操作恢复。弹窗打开、游戏已结束或等待选择是否继续时，方向输入不触发移动音效。
